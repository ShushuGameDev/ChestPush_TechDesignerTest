# 脚本模块索引

这是模块文档的二级入口。首次进入项目时先阅读仓库根目录 [README.md](../../README.md)，再根据任务阅读本索引和对应模块文档。

## 维护规则

- 每个实际模块使用一份同名 Markdown 文档：`Docs/ScriptModules/<模块名>.md`。
- 新增模块时先建文档并在下方登记；修改模块后同步更新文档。
- 文档描述当前实现，不把计划写成已完成；未实现内容标注“计划中”。
- 模块文档至少说明职责、主要文件、依赖、场景或 Prefab 挂载点、输入与事件、资源引用、存档字段、验证方式和已知风险。不适用的项目写“无”。
- 多模块行为分别在各自文档说明边界，并用相对链接交叉引用。
