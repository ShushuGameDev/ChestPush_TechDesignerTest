# 关卡编辑器

## 职责

提供 UI Toolkit 关卡目录图与 Scene 视图 3D 格子编辑器；修改后保存 JSON，并接入 Unity Undo。

## 主要文件

已实现：`Assets/Editor/LevelEditor/` 中的 `LevelGraphWindow`、`LevelPaintTool`、`LevelPalettePanel`、`EditorSessionService`、`ProjectValidator`、`BaseAssetsInstaller`。

## 依赖与协作边界

使用[关卡数据](./LevelData.md)的解析与校验，不复制运行时规则。编辑器不将预览对象保存进运行时场景。

## 场景或 Prefab 挂载点

关卡目录和 Palette 共用 `ChestPush Levels` EditorWindow。二级编辑使用 SceneView 的 EditorTool 绘制，窗口切换为 Palette；默认镜头为 45° 俯视，可绕当前关卡中心按 45° 步进平滑旋转。

## 输入、事件与对外接口

`Tools > ChestPush > Level Editor` 打开目录。输入 `easy_00_guide` 一类文件名创建节点；新节点优先放在当前目录视窗中心，位置冲突时向附近空位错开。选中后可重命名、设置入口与解锁、调整选关及后继顺序。目录图使用无边界逻辑坐标，不显示水平或垂直滚动条；视窗只保存平移偏移和缩放值，不为远处空白创建网格或元素。可见网格按当前视窗即时绘制。按住 Ctrl 滚动滚轮，以鼠标位置为中心在 35%～200% 范围缩放；按住鼠标中键拖动可向任意方向平移视窗。选中节点后点击工具栏 `Focus (F)` 或在目录图获得焦点时按 F，将节点中心自动对齐到视窗中心。拖动空白处可框选节点，Shift/Ctrl 可在框选时保留已有选择；拖动任一已选节点会一起移动整组选中节点，并作为一次 Undo 保存。多选时右侧单节点设置面板停用。无连接时节点的输入端口在左缘、输出端口在右缘；建立连接后，端口依据相连节点的位置自动选择上下左右边缘及边缘上的落点。一个端口连接多个节点时，以这些节点的整体位置选择共用落点；同侧进出端口距离过近时会自动错开。拖动节点时端口和连线实时更新。从输出端口按住左键拖动时显示临时连线，有效目标的输入端口会高亮，松手落在另一节点的输入端口或节点主体上即建立链接。连线按端口朝向、对齐程度与距离自适应：端口对向且近乎共线或相距很近时为直线，适合直角转弯时为二次曲线，其余情况为沿端口外法线延伸的三次贝塞尔曲线。各线型之间平滑过渡，避免拖动节点时在距离阈值处突然变形。每条连线在目标端前方绘制指向目标节点的箭头，箭头沿曲线切线旋转；拖动创建连接时也显示方向箭头。极短连线不绘制箭头，以免遮住端口。拖到空白处松手或按 Esc 取消；节点主体仍用于拖动节点位置，允许负坐标，并按画布逻辑坐标保存，不受当前视图偏移或缩放影响。点击 `Edit 3D level` 进入 SceneView 绘制模式，同时关卡编辑器窗口切换为 Palette。Palette 提供层切换与新增、地基/结构/标记/箱子素材过滤；Blocks 以 Prefab 缩略图和方块 ID 的网格卡片显示，选中项高亮。

SceneView 获得焦点时，Q 逆时针、E 顺时针平滑旋转视角 45°；B 切换单格画笔，R 切换矩形工具。矩形工具的左键拖动会显示范围、尺寸和格数预览，松手后一次性提交，Esc 取消；`Fill` 填满矩形，`Outline` 只处理边框。批量放置只支持 `Floor` 与 `Structure`，`Marker` 和 `Box` 保持单点放置；启用 `Erase brush` 后，任意当前槽位都可用矩形擦除，每格沿用单格擦除顺序（箱子、结构、标记、地块），不受当前槽位限制。一次矩形操作最多处理 4096 格，并只产生一次 Undo、一次校验和一次 JSON 保存。同种结构已存在时保留原实例 ID 与机关配置。单格画笔左键放置或擦除，右键选择并编辑机关属性；单格 `Erase brush` 每次只擦除所点格子的一项。新关卡默认含空的 `baseY=0` 地基层。

放置目标点到箱子所在格、或放置箱子到目标点所在格，都会被关卡校验拒绝，Palette 显示冲突格坐标，当前 JSON 不变。

在 SceneView 悬停编辑格子时，若鼠标射线先穿过当前层墙体再到达该格子的地块，挡住视线的墙体临时以 80% 不透明度绘制；鼠标移开后恢复。其他墙体及编辑数据不变。

Palette 顶部显示自动保存状态和最近保存时间；机关属性输入须点击对应 `Apply`。点击“保存并返回目录”会再同步一次 JSON，保存成功后退出绘制工具并将同一窗口切回目录；保存失败则留在 Palette 显示错误。目录窗口也显示最近保存状态。

`LevelGraphWindow` 订阅编辑会话和 SceneView 选择事件，窗口停用时取消订阅。Palette 随编辑状态刷新；Prefab 预览由 `AssetPreview` 异步加载，加载前显示资源小图标。

目录刷新会取消正在拖动的临时连线。连线操作复用目录服务校验，源、目标节点不存在或自连线时不会改写目录；重复连接保持幂等。JSON 写入先写同目录临时文件并尝试文件替换；若 Windows 替换操作偶发抛出 `IOException`，会尝试用临时文件覆盖写回目标，覆盖成功后删除临时文件。

## 资源引用与生命周期

总表提供可选 Prefab 与 Addressables 地址。首次缺少总表时自动生成九种基础资源，也可执行 `Tools > ChestPush > Create Base Assets`。Palette 缩略图读取总表指向的 Prefab；SceneView 关卡预览使用 Handles，不向主场景创建对象。方块按镜头深度排序并启用深度测试，遮挡关系不依赖 JSON 放置顺序；悬停边框仍保持可见。

## 存档字段

每次有效操作保存对应关卡或目录 JSON。节点只保存 `editorX/editorY` 逻辑坐标；无限视图不扩展 JSON，也不持久化空白网格。视窗平移与缩放仅序列化在当前 EditorWindow 状态中。画笔/矩形、填充/边框和擦除选择仅保存在临时编辑会话，不写入关卡 JSON；矩形拖动期间也只保存起止格，松手时才批量修改关卡。临时 ScriptableObject 存编辑状态，Unity Undo/Redo 后回写 JSON 与刷新预览。

## 验证方式

`Tools > ChestPush > Validate Project` 检查数据与 Addressables；`Tools > ChestPush > Run Targeted EditMode Checks` 只运行 `ChestPush.Tests`。既有逻辑已通过 Unity MCP 确认脚本编译和定向测试，并以临时关卡验证创建、撤回、重做、删除各阶段的 JSON、目录和 Addressables 一致性；临时关卡已清理。失效源节点和自连线均会被拒绝，目录 JSON 保持不变。目录图无限视窗、缩放、平移和节点聚焦已通过脚本校验与 Unity 编译；窗口视觉树确认不存在 `ScrollView`/`Scroller`，调用聚焦后所选节点中心与视窗中心重合。新节点中心定位、避让节点占位、框选/多选移动、替换失败回退、端口自动定位、自适应连线和方向箭头已实现；`dotnet build ChestPush.Editor.csproj --no-restore` 编译通过，Unity Editor 重编译后 Console 无脚本错误，鼠标交互尚待 Unity 窗口人工验收。矩形逻辑检查覆盖了 3×2 填充、3×3 边框、4096 格上限、同种结构实例保留和按槽位擦除。Palette 合并和墙体悬停淡化已通过 Unity Console 检查编译；墙体射线几何检查覆盖了遮挡格与相邻无遮挡格。尚未人工逐项验收目录图鼠标交互、矩形拖动、节点拖拽和 Palette 交互。

## 已知风险与待办

编辑会话只在当前 Unity 域中保存撤回历史。未完成的草稿允许保存，但运行前必须通过严格校验。当前 `easy_00_guide` 仍是编辑草稿。
